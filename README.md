# bellwether-agent

An autonomous agent that monitors institutional 13F portfolios, decides on
its own what is worth investigating, and produces sourced briefing memos.

A bellwether is the security, or the investor, whose move the rest of the
market follows. The name is the job: notice who moved first, and work out
what it means.

Work in progress. Setup instructions, architecture, and results will be
documented here as the project develops.
